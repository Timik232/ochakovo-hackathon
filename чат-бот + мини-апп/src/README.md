# Симулятор заводчанина — Telegram Mini App

Мемная игра про смену на заводе «Очаково» в формате мини-аппа Telegram: шесть профессий, наставник Михалыч, аттестация по истории компании, в конце — подходящие вакансии, анкета на практику и доска почёта.

## Что внутри

| Файл | Зачем |
|---|---|
| `public/index.html` | Сама игра, одним файлом. Портретное поле 9:16 под телефон. |
| `server.js` | Сервер на Node.js 18+ без зависимостей: раздаёт игру, принимает анкеты и очки, проверяет подпись Telegram, отвечает боту на `/start`, пересылает анкеты в чат HR. |
| `.env.example` | Переменные окружения. |
| `src/` + `build.py` | Исходники игры по частям. После правок: `python3 build.py` пересобирает `public/index.html`. |
| `data/` | Создаётся сервером: `applications.jsonl` (анкеты) и `scores.json` (доска почёта). |

## Что умеет внутри Telegram

- Нативная кнопка внизу (MainButton) дублирует главную кнопку каждого экрана.
- Вибрация на попаданиях, промахах и авариях.
- Имя игрока и ФИО в анкете подставляются из профиля Telegram.
- Номер телефона — кнопкой «Из Telegram», с согласия пользователя.
- Свайп вниз не закрывает игру (важно для уровня с мешалкой), во время смены Telegram переспрашивает перед закрытием.
- Ссылки на hh.ru и ochakovo.ru открываются во встроенном браузере, «Позвать друга» — через окно «Поделиться».
- Без Telegram (обычный браузер) игра тоже работает: анкету предлагается отправить письмом, доска почёта только для чтения.

## Запуск за 15 минут

1. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot` → имя и username → получить `BOT_TOKEN`.
2. **Хостинг с HTTPS.** Telegram открывает мини-аппы только по `https://`. Подойдёт любой VPS с доменом и сертификатом (nginx + Let's Encrypt) или PaaS, где можно запустить Node.js (Render, Railway, Yandex Cloud Serverless Containers, Timeweb Cloud Apps и т. п.).
3. **Чат для анкет.** Создайте группу HR, добавьте туда бота. Чтобы узнать её id: напишите в группе любое сообщение и откройте `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` — нужен `chat.id` (обычно начинается с `-100`). Пока бот запущен с опросом, getUpdates занят — посмотрите id до первого запуска или временно поставьте `BOT_POLLING=0`.
4. **Запуск.**
   ```bash
   BOT_TOKEN=... WEBAPP_URL=https://game.example.ru HR_CHAT_ID=-100... node server.js
   ```
   Сервер слушает `PORT` (по умолчанию 8080) — проксируйте на него домен.
5. **Подключить мини-апп к боту.** В BotFather: `/mybots` → бот → *Bot Settings* → *Configure Mini App* → *Enable Mini App* → указать `WEBAPP_URL`. Так у бота появится кнопка «Запустить» в профиле и ссылка вида `https://t.me/<бот>?startapp`. Для отдельной прямой ссылки — `/newapp` (получится `https://t.me/<бот>/<короткое_имя>`).
6. **Ссылка «Позвать друга».** В `src/tg.js` поменяйте `CONFIG.shareUrl` на ссылку из шага 5 и выполните `python3 build.py`.

Сервер сам ставит боту кнопку меню «Играть» и отвечает на `/start` сообщением с кнопкой запуска. Если у бота уже есть другой бэкенд, запустите с `BOT_POLLING=0` — тогда сервер только раздаёт игру и принимает анкеты.

## Безопасность и данные

- Каждый запрос с анкетой или очками подписан Telegram (`initData`); сервер проверяет подпись токеном бота и отклоняет данные старше суток. Подделать имя или id пользователя без токена нельзя.
- Сервер повторно проверяет обязательные поля и возраст 18+, ограничивает частоту запросов.
- Анкеты — это персональные данные. Перед запуском нужны: политика обработки ПДн (ссылку можно указать в BotFather → *Bot Settings* → *Privacy Policy*), хранение данных на серверах в РФ (152-ФЗ, ст. 18 ч. 5) и согласие в форме — оно уже есть, текст стоит сверить с юристами.
- Хранилище — JSON-файлы, этого хватит на тысячи анкет. Для большого запуска замените `appendApplication` и `scores` в `server.js` на базу данных.

## Шрифты

Игра берёт Montserrat и Neucha с Google Fonts. Если в целевой аудитории Google Fonts открываются медленно, скачайте шрифты в `public/fonts/` и замените `<link>` в `src/head.html` на `@font-face` — игра и без них работает на запасных шрифтах.
