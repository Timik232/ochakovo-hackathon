# «Очаково» — Влейся в команду 🥤

**HR-кампания и цифровые продукты для привлечения молодых специалистов на производство «Очаково».**

Молодёжь мало знает о работе на заводе и часто не доходит до отклика. Мы превращаем знакомство с профессией в игру и лендинг с честными условиями: за 3–5 минут в Telegram можно «поработать» на линии розлива, в лаборатории или у варочного котла, узнать зарплаты и график — и заполнить анкету прямо в том же интерфейсе. Кампанию поддерживают плакаты, сторис и видео в единой комикс-стилистике «Влейся в команду».

## Игра «Симулятор заводчанина»

Один день на заводе — от раздевалки до аттестации. В игре 6 мини-игр по настоящим профессиям «Очаково»:

- 📦 **08:00 · Склад** — собери паллет из упаковок кваса (башенка-стакер)
- 🍾 **10:00 · Цех розлива** — сбивай брак с конвейера: без крышки, недолив, кривая этикетка
- 🧪 **12:00 · Лаборатория** — 10 проб на контроль качества: годен или брак?
- 🎛️ **14:00 · Пульт управления** — держи 4 стрелки приборов в зелёной зоне
- 🍋 **16:00 · Отдел новых вкусов** — собери рецепт напитка и отдай комиссии
- 🔨 **18:00 · Технологический цех** — доберись до люка котла с мешалкой (да, как в Getting Over It)

Вечером — аттестация: Михалыч, наставник смены, проверит, запомнил ли игрок реальные факты о заводе. Финал — анкета соискателя, которая уходит HR, и место в таблице лидеров.

**Технически:** весь фронтенд — ванильный JS + Canvas 2D (~174 КБ одним файлом, вся графика и звук генерируются кодом, ноль ассетов). Бекенд бота — Node.js **без единой npm-зависимости**: проверка подписи Telegram initData (HMAC-SHA256), лидерборд, приём анкет, пересылка в HR-чат. 50 автотестов, Docker, секреты в HashiCorp Vault.

```bash
# запустить бота локально
cd "чат-бот + мини-апп/src"
cp .env.example .env        # вписать BOT_TOKEN от @BotFather
npm install && npm start    # http://localhost:8080

# тесты
npm test                    # 50 passed
```
