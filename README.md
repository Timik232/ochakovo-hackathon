# Хакатон «Очаково»

Публичный репозиторий с материалами проекта для хакатона «Очаково»: презентацией, промороликом, маркетинговым планом, чат-ботом и мини-приложением, лендингом, плакатами, видеоматериалами и HR-брендом.

> **Статус:** пока создана только структура репозитория. Документы, изображения, видео и исходный код будут добавлены позже. Перечисленные ниже файлы **ещё не загружены**.

Внутреннюю структуру `src/` следует сохранить такой, какой она есть в работающем проекте: показанные `backend/`, `frontend/` и `db.sql` — только пример из схемы, а не обязательный шаблон.

## Как добавить материалы

1. Откройте нужную папку на GitHub и выберите **Add file → Upload files**; либо скопируйте файлы в локальный клон репозитория и отправьте изменения через Git.
2. Для файлов исходного кода добавляйте исходники и файлы зависимостей (`package.json`, lock-файлы, `requirements.txt` и т. п.), **не** загружайте `node_modules/`, `.env` и секреты.
3. Если размер видео или другого файла превышает **100 МиБ**, используйте Git LFS либо внешнее файловое хранилище со ссылкой в README — обычный GitHub не принимает такие файлы через Git.
4. После загрузки материалов обновите этот README: укажите названия итоговых работ, участников и, если нужно, инструкции по запуску.

Публичность репозитория позволяет просматривать его содержимое всем желающим. Перед загрузкой убедитесь, что материалы можно публиковать.
